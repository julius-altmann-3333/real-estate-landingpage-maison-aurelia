# Maison Aurelia — Luxury Real Estate Landing Page

Bootstrap 5.3 responsive luxury real-estate landing page.

## Included
- Responsive Bootstrap layout
- Luxury editorial design system
- Mobile off-canvas navigation
- Clickable property gallery
- Property statistics
- Features/amenities
- Video section + modal
- Google Maps embed
- Horizontal similar-properties slider
- Instagram-style preview
- Private viewing contact form with front-end validation
- EN/DE language switch foundation
- Scroll-to-top button
- IntersectionObserver animations
- Standalone JS files

## Important
The images, video, Google Maps location, Instagram links, contact details and demo URLs are placeholders. Replace them with production assets/data.

The contact form currently validates in the browser only. Connect `js/contact-form.js` to your backend or CRM before production.

External dependencies are loaded from CDNs.
